# 🚀 OpenCode Custom AI Mod — Gwarden.su Provider

> **Мод для OpenCode с поддержкой внешнего AI-провайдера [Gwarden AI](https://gwarden.su/cabinet), выбором моделей и решением проблемы с нехваткой токенов.**

В мод уже встроены и настроены:
- ⚡ **DeepSeek V4 Flash (Бесплатный / Free)** — быстрая модель с окном контекста **1 000 000 токенов**, нулевая стоимость токенов, отличный выбор когда кончаются лимиты.
- 🧠 **Google Gemini 4 Argon** — новейший флагман Google DeepMind с контекстом **1M токенов** для сложной архитектуры, написания кода и глубокого анализа репозиториев.
- 🔄 Возможность переключаться на любую другую модель из каталога провайдера (DeepSeek V4 Pro, Claude Fable 5.1, Qwen 3.8 Max и др.).

---

## 📌 Зачем нужен этот мод?

При активной разработке в OpenCode стандартные лимиты токенов быстро исчерпываются. Данный мод перенаправляет запросы OpenCode на OpenAI-совместимый шлюз **Gwarden AI** (`https://gwarden.su/v1`), что даёт:
1. **Бесплатный DeepSeek V4 Flash** — пишите код без страха сжечь весь баланс.
2. **Флагманский Gemini 4 Argon** — максимальная точность в сложнейших алгоритмах и тестах.
3. **Огромный контекст 1M токенов** — скормите модели весь проект целиком.
4. **Удобный выбор модели в один клик** как через CLI-меню, так и прямо внутри интерфейса OpenCode (команда `/gwarden`).

---

## 🔑 Шаг 1. Получение API-ключа

1. Перейдите в личный кабинет: **[https://gwarden.su/cabinet](https://gwarden.su/cabinet)**.
2. Войдите через Telegram-бота сервиса.
3. Нажмите кнопку **«Получить API»** (доступен бесплатный 7-дневный пробный период / бесплатные модели).
4. Скопируйте ваш API ключ — он выглядит как `GWAR-XXXXXXXXXXXXXXXX`.

## ⚡ Шаг 2. Быстрый запуск

### Вариант А: Интерактивный помощник (самый простой)

Запустите команду в терминале:

```bash
npm start
```
или
```bash
node bin/switch.js
```

Откроется русскоязычное интерактивное меню:

```text
╔══════════════════════════════════════════════════════════════════════╗
║               🚀 OpenCode Custom AI Mod (Gwarden.su)                 ║
║  Выбор своей ИИ: Gemini 4 Argon & DeepSeek V4 Flash (Бесплатный)     ║
╚══════════════════════════════════════════════════════════════════════╝

Текущие настройки:
  🔌 Провайдер:      Gwarden AI (https://gwarden.su/v1)
  🔑 API Ключ:       GWAR-ab12...cd34
  🤖 Активная ИИ:    DeepSeek V4 Flash (Бесплатный) [БЕСПЛАТНЫЙ] (gwarden/deepseek-v4-flash)
  📁 Личный кабинет: https://gwarden.su/cabinet
──────────────────────────────────────────────────────────────────────
Меню действий:
  [1] ⚡ DeepSeek V4 Flash (Бесплатный / 1M токенов / экономия токенов)
  [2] 🧠 Google Gemini 4 Argon (Google DeepMind / 1M токенов / кодинг)
  [3] 📋 Ввести другую модель или просмотреть каталог gwarden.su
  [4] 🔑 Указать / изменить API ключ (https://gwarden.su/cabinet)
  [5] 📡 Проверить соединение с сервером Gwarden
  [6] ⚙️ Применить настройки в OpenCode (~/.config/opencode/opencode.json)
```

1. Нажмите `[4]` и вставьте ваш ключ `GWAR-...`
2. Нажмите `[1]` для выбора бесплатного **DeepSeek V4 Flash** или `[2]` для **Gemini 4 Argon**.
3. Нажмите `[5]` для проверки связи с сервером.
4. Нажмите `[7]` для запуска OpenCode!

### Вариант Б: Быстрые команды в терминале

Переключение модели в одну строку:

```bash
# Переключиться на бесплатный DeepSeek V4 Flash:
node bin/switch.js --model deepseek-v4-flash

# Переключиться на флагманский Google Gemini 4 Argon:
node bin/switch.js --model gemini-4-argon

# Задать ключ:
node bin/switch.js --key GWAR-ВАШ_КЛЮЧ

# Проверить статус:
node bin/switch.js --status

# Проверить подключение и задержку к API:
node bin/switch.js --check
```

---

### Вариант В: Переключение прямо внутри OpenCode (TUI мод)

Мод регистрирует слэш-команду внутри самого OpenCode:

1. В строке ввода OpenCode введите:
   ```text
   /gwarden
   ```
2. Откроется всплывающее диалоговое окно со списком:
   - `⚡ DeepSeek V4 Flash (Бесплатный)`
   - `🧠 Google Gemini 4 Argon`
   - `🔑 Указать / изменить API ключ`
   - `🔄 Загрузить все модели из кабинета gwarden.su`
3. Выберите нужную модель стрелочками и нажмите **Enter**. OpenCode мгновенно переключит активную нейросеть!

## 🛠 Ручная настройка через `opencode.json`

Если вы предпочитаете настраивать OpenCode вручную, готовый файл `opencode.json` уже лежит в корне проекта. Вы можете скопировать его в `~/.config/opencode/opencode.json` или оставить в проекте:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "model": "gwarden/deepseek-v4-flash",
  "provider": {
    "gwarden": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "Gwarden AI",
      "options": {
        "baseURL": "https://gwarden.su/v1",
        "apiKey": "{env:GWARDEN_API_KEY}"
      },
      "models": {
        "deepseek-v4-flash": {
          "name": "DeepSeek V4 Flash (Бесплатный)",
          "limit": {
            "context": 1048576,
            "output": 32768
          }
        },
        "gemini-4-argon": {
          "name": "Google Gemini 4 Argon",
          "limit": {
            "context": 1048576,
            "output": 65536
          }
        }
      }
    }
  }
}
```

Для передачи ключа через переменную окружения:
```bash
export GWARDEN_API_KEY="GWAR-ВАШ_КЛЮЧ"
```

## 📁 Структура проекта

- `bin/switch.js` — Интерактивный CLI терминал для управления ключом и выбора ИИ.
- `index.js` — Серверный плагин OpenCode (динамическая регистрация провайдера Gwarden).
- `tui.js` — TUI-плагин для интерфейса OpenCode (команда `/gwarden` и диалоги).
- `src/models.js` — Характеристики моделей, контекстные лимиты и описания.
- `src/config.js` — Чтение и запись конфигураций OpenCode и хранилища мода.
- `src/api.js` — Взаимодействие с API `https://gwarden.su/v1` (тест связи, получение моделей).
- `opencode.json` — Рабочий конфигурационный файл для OpenCode.
- `install.sh` — Скрипт автоматической установки.

## ❓ Частые вопросы (FAQ)

**В: Где взять API-ключ?**  
О: В личном кабинете [https://gwarden.su/cabinet](https://gwarden.su/cabinet) через Telegram-бота. Ключ начинается с префикса `GWAR-`.

**В: Точно ли DeepSeek V4 Flash бесплатный?**  
О: Да, на Gwarden модель `deepseek-v4-flash` предоставляется бесплатно для генерации кода и экономии вашего баланса.

**В: Как узнать, что OpenCode подхватил модель?**  
О: Выполните команду `npx @opencode/cli models` — в списке появятся `gwarden/deepseek-v4-flash` и `gwarden/gemini-4-argon`.
